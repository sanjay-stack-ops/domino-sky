## 📌 About the Project

Domino Sky is an interactive flight network disruption and recovery simulator designed to demonstrate how disruptions in airline operations can create cascading delays across interconnected flight networks.

It explores how a delay at one airport can affect other flights, aircraft schedules, and connected routes.

## 🎯 Problem Statement

A 90-minute thunderstorm in Mumbai can disrupt flight operations and potentially create cascading delays across an interconnected airline network.

Understanding these dependencies is important for effective airline operations and recovery planning.

## 💡 Project Objectives

- Visualize interconnected flight networks.
- Understand cascading flight delays.
- Explore weather-related flight disruptions.
- Analyze the impact of disruptions on connected flights.
- Explore possible recovery strategies.

## 🌩️ Example Scenario

Imagine a severe thunderstorm affecting Mumbai airport.

A delayed incoming flight may affect the next scheduled flight using the same aircraft. This can create additional delays across the network.

Domino Sky explores this chain reaction through simulation.
